# 🛒 21vek.by Products Search Ranking

Решение задачи ранжирования товаров в поисковой выдаче интернет-магазина **21vek.by** (Learning-to-Rank).

## 🏆 Результат
* **Kaggle Score:** `0.61`

## 🛠 Что сделано
* **EDA и очистка данных:** анализ поисковых сессий, целевых действий и признаков товаров.
* **Feature Engineering:** текстовые признаки (совпадение запроса и названия), ценовые агрегации внутри запроса (`query_id`) и поведенческие факторы.
* **Валидация и моделирование:** настройка кросс-валидации без утечек данных по группам запросов, обучение градиентного бустинга.

## 🚀 Запуск
1. Скачайте данные соревнования с Kaggle и положите в папку проекта (`.csv` добавлены в `.gitignore`).
2. Установите зависимости: `pip install pandas numpy scikit-learn lightgbm catboost`
3. Откройте и запустите ноутбук `21vek.by_products_search_ranking.ipynb`.
